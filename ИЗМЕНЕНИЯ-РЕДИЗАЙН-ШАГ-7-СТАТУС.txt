РЕДИЗАЙН, ШАГ 7 ИЗ 8 — ЧАСТЬ 1: СТРАНИЦА СТАТУСА МОДЕЛЕЙ (2026-11-25)
=====================================================================

Что это
-------
Седьмой шаг замены оформления Premier разбит на три поверхности: страница статуса моделей, кабинет
разработчика API и панель администратора. В этой поставке сделана только страница статуса. Кабинет
разработчика и панель администратора не начаты (подробности и порядок — в CORE-DESIGN-SYSTEM.md, раздел 17).

Страница:  /status (перенаправляет на /status.html), только на русском
Описание:  CORE-DESIGN-SYSTEM.md, раздел 17.1

Что сделано
-----------
1. Страница переведена на систему Core: токены, базовые стили, компоненты, сцена и подсказки Core.
   Ядро стоит в правом верхнем углу, без движения; сцена грузится после загрузки страницы в свободное время.
2. Шрифт Onest теперь из /fonts. Раньше страница тянула шрифт с Google Fonts (другой домен).
3. Нативные подсказки title у сегментов с ошибками заменены подсказками Core. Сегменты с ошибками теперь
   доступны с клавиатуры (Tab) и показывают ту же подсказку при фокусе, что и при наведении.
4. На сенсорных экранах у сегментов с ошибками есть невидимая область нажатия 44 px; сами полоски не меняются.
5. Цвета статуса (зелёный, красный) только там, где это статус. Значок без данных — нейтральный.
6. Текст, логика и все идентификаторы скрипта сохранены. Серверный код и API не менялись.

Файлы
-----
Новые:
- public/core/core-status.css — стили страницы
- public/core/core-status.js — размещение Ядра
Изменённые:
- public/status.html — подключения Core, подсказки, без внешнего шрифта
- CORE-DESIGN-SYSTEM.md — раздел 17 и шапка
Удалённых файлов нет. Старые стили страницы встроены в HTML и удалены вместе с ним.
Папка desktop/ не трогалась.

Как применить
-------------
1. Резервная копия: cp -a /opt/premier /opt/premier.bak-2026-11-25-status
2. Распаковать архив поверх проекта (data/ и .env в архиве нет).
3. npm install не нужен. systemctl restart premier.

Проверено
---------
- Браузер (Chromium): страница с данными в тёмной и светлой теме, 1440 и 390 px. Ошибок в консоли нет.
  Запросов к другим доменам нет. Атрибутов title на странице нет.
- Подсказка сегмента с ошибкой: показывается при наведении и при фокусе с клавиатуры.
- Данные для проверки подставлены через перехват /api/models/status: настоящих пингов в песочнице нет.
- npm test: 481 тест, 459 прошли, 13 упали. Двенадцать из них падали и до шага (облачный компьютер, архив папки,
  проекты в чате, подпись desktop-помощника). Тринадцатый — CLD-09 («Стоп» в чате), он нестабилен: при повторном
  запуске отдельно один прогон прошёл, другой упал. К странице статуса он не относится.

Не проверено
------------
- Настоящие данные пингов и реальный ответ сервиса статуса.
- Safari, Firefox, настоящий телефон и экранный диктор.
- Кабинет разработчика и панель администратора: не переделаны, см. раздел 17.
